# Tu agente de reels virales con Claude Code

Guía gratis en español de [@soydiegoosorio](https://instagram.com/soydiegoosorio): cómo hacer que Claude Code estudie los reels que más pegan en tu nicho (descargar, transcribir con Whisper, ver cuadro por cuadro con ffmpeg, desarmar en formatos) y crear un subagente que te escriba los tuyos.

**Página:** https://diegodoc1111.github.io/agente-reels-virales/

## Fuentes verificadas (10-nov-2026)
- Instalación de Claude Code: https://code.claude.com/docs/en/setup
- Subagentes de Claude Code (carpeta .claude/agents): https://code.claude.com/docs/en/sub-agents
- yt-dlp: https://github.com/yt-dlp/yt-dlp · ffmpeg: https://ffmpeg.org · Whisper: https://github.com/openai/whisper
