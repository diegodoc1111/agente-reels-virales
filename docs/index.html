Ten tu cuenta de Claude con plan Pro

2

Instala Claude Code

Escribe terminal en el buscador de tu computador y ábrela. Pega el comando de tu sistema y dale Enter. No muestra avance mientras descarga: espera a que termine.

WINDOWS
Windows PowerShell
irm https://claude.ai/install.ps1 | iex
MAC
Terminal
curl -fsSL https://claude.ai/install.sh | bash

Cuando termine, cierra la terminal y vuelve a abrirla. Los comandos son los de la página oficial de instalación. ¿Prefieres sin terminal? La app de Claude para el computador trae Claude Code en la pestaña Code.

3

Escribe claude e inicia sesión

Crea una carpeta en Documentos llamada mis-reels. Luego, en la terminal:

WINDOWS
Windows PowerShell
cd Documentos\mis-reels
claude
MAC
Terminal
cd ~/Documents/mis-reels
claude

La primera vez te abre el navegador para entrar con tu cuenta de Claude. Entras, vuelves a la terminal y ya está Claude Code esperando tu mensaje. Si te pide permiso para crear archivos o instalar algo, acéptalo: así trabaja.

4

Instala las herramientas

Dentro de Claude Code pega esto:

Claude Code
Instálame yt-dlp, ffmpeg y Whisper en este computador, revisa que funcionen y avísame cuando estén listos.

Si te pide permiso para instalar algo, acéptalo.

5

Junta los reels que más pegan

Copia los links de los 10 a 20 reels con más vistas de tu nicho (Instagram, TikTok o YouTube Shorts) y pégalos en un archivo links.txt dentro de tu carpeta. Luego:

Claude Code
Descarga todos los videos de links.txt en una carpeta llamada reels. Si alguno no baja, dime cuál y sigue con el resto.

Instagram a veces pide iniciar sesión para descargar. Si falla, prueba con TikTok o YouTube Shorts, o descarga tú los videos desde el celular y ponlos en la carpeta.

6

Que los vea cuadro por cuadro

Claude Code
Para cada video de la carpeta reels: transcribe cada palabra con Whisper, con el segundo exacto en que se dice, y saca un cuadro cada 0,3 segundos con ffmpeg. Luego mira los cuadros y escribe qué pasa en pantalla en cada momento: textos, cortes, cambios de plano y efectos. Guarda todo en una carpeta llamada estudio.

Esta es la parte que nadie hace: entender no solo lo que dicen, sino lo que se ve.

7

Desármalos en formatos

Claude Code
Con todo lo de la carpeta estudio, desarma cada reel: el gancho de los primeros 3 segundos, cada cuánto hay un corte, cómo está armado el argumento y cómo cierra. Agrupa los que se parecen en formatos, cada uno con su plantilla y un ejemplo, y dime qué tienen en común los que más vistas tienen.
8

Conviértelo en tu agente

Claude Code
Con los formatos que encontraste, crea un subagente llamado analista-viral: que sepa estos patrones, que pueda estudiar reels nuevos con el mismo método y que me escriba guiones para mi negocio, [tu negocio], siguiendo los formatos que más pegan. Guárdalo para usarlo siempre.

Desde ahí, cada vez que lo necesites:

Claude Code
Usa el analista-viral para escribirme 3 guiones sobre [tema], con el formato que mejor le funcione a mi nicho.

Claude Code guarda tus subagentes en la carpeta .claude/agents. Repite los pasos 5 a 7 cada mes con los reels nuevos y tu agente se mantiene al día.
